# 个人主页

电气工程硕士在读，电力系统及其自动化方向。关注新能源并网、新能源设备建模与电力系统稳定性分析，日常用 Simulink 和 PSCAD 建模，也做短路电流计算与暂态电压相关的分析。

这个仓库是个人主页的源码，放了在读期间做的课题、常用的工具、教育与实习经历，以及发表过的论文。

**站点：https://xllll67.github.io/**

## 内容的组织方式

首页是一个等距视角的 3D 房间，点房间里的物件打开对应板块：

| 物件 | 打开什么 |
| --- | --- |
| 桌上显示器 | 项目与课题 |
| 书架 | 技能与工具 |
| 墙上画框 | 教育与实习经历 |
| 地上纸箱 | 论文与笔记 |
| 台灯 | 不是入口，点它切换白天 / 夜晚 |

也可以直接看文字版：`https://xllll67.github.io/site.html`。手机屏幕窄，访问首页会自动跳到这里。

## 怎么改内容

所有文字都在 `data.json` 一个文件里，改完提交，约一分钟后生效，不需要构建。

| 字段 | 对应什么 |
| --- | --- |
| `site` | 姓名、左上角方块字母、身份、简介、城市、邮箱、外链 |
| `projects` | 项目与课题 |
| `skills` | 技能分组 |
| `experience` | 教育与实习经历 |
| `posts` | 论文、专利、笔记 |

两个数量上的限制：显示器屏幕上最多画 4 条项目，墙上画框只画前 3 条经历，超出的只在弹窗里可见。

## 技术实现

纯静态，没有构建步骤，推送到 `main` 分支即由 GitHub Pages 发布。

3D 房间用 three.js 搭成，库文件存在本地，不依赖 CDN。房间里的家具全部由代码几何体拼出，没有模型文件，所以调整布局不需要建模软件。文字版在 `site.html`，与 3D 版共用同一份 `data.json`。

想在本地预览，需要起一个 HTTP 服务（直接双击 HTML 打不开）：

```bash
python -m http.server 8642
```

然后访问 `http://127.0.0.1:8642`。
